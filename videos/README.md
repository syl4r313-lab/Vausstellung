# Videos

Lege hier deine MP4-Dateien ab und passe die Liste `videoSources` in `index.html` entsprechend an:

```
videos/video1.mp4
videos/video2.mp4
videos/video3.mp4
videos/video4.mp4
```

Falls du andere Dateinamen oder mehr/weniger Rahmen brauchst, passe `videoSources` und `framePositions` in `index.html` an.
